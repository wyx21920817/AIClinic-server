# ECG迁移学习系统项目概览

## 🎯 项目简介

本项目实现了一个完整的ECG（心电图）迁移学习微调系统，支持两种微调方法：
1. **传统微调方法** - 直接在LTDB数据上微调预训练模型
2. **迁移学习方法** - 通过导联适配器实现2导联→12导联转换的迁移学习

## 🔧 核心组件详解

### 1. 导联适配器 (LeadAdapter)

**功能**: 将2导联ECG信号转换为12导联信号
**类型**: 
- `basic`: 基础卷积适配器
- `attention`: 带注意力机制的适配器

**架构**:
```python
class LeadAdapter(nn.Module):
    def __init__(self, in_channels=2, out_channels=12, adapter_type='basic'):
        # 2导联 → 12导联转换
        # 支持基础卷积和注意力机制
```

### 2. 迁移学习模型 (TransferLearningModel)

**功能**: 整合导联适配器和预训练主干网络
**特性**:
- 自动加载预训练权重
- 灵活的冻结策略
- 参数统计和模型保存

**架构**:
```python
class TransferLearningModel(nn.Module):
    def __init__(self, backbone_path, num_classes=5, adapter_type='basic', 
                 freeze_backbone=True, freeze_stages=None):
        self.lead_adapter = LeadAdapter(...)
        self.backbone = XResNet1d101(...)
```

### 3. 训练器 (TransferLearningTrainer)

**功能**: 完整的训练流程管理
**特性**:
- 自动训练/验证循环
- 早停和学习率调度
- 最佳模型保存
- 训练历史可视化

### 4. 配置系统

**功能**: 集中管理训练配置
**配置类型**:
- `basic`: 基础迁移学习
- `progressive`: 渐进式解冻
- `attention`: 注意力机制
- `multitask`: 多任务学习
- `advanced`: 高级组合策略
- `quick_test`: 快速测试

## 🚀 使用流程

### 传统微调流程
```bash
# 1. 数据预处理
python code/data_ltdb.py

# 2. 基础训练
python code/finetune_ltdb_advanced.py --config basic

# 3. 微调
python code/finetune_ltdb_advanced.py --config deep
```

### 迁移学习流程
```bash
# 1. 数据预处理
python code/data_ltdb.py

# 2. 运行迁移学习
python run_transfer_learning.py --config basic

# 3. 测试验证
python test_transfer_learning.py
```

## 📊 配置对比

| 方法 | 优势 | 劣势 | 适用场景 |
|------|------|------|----------|
| **传统微调** | 直接、简单 | 需要更多计算资源 | 资源充足、追求最佳性能 |
| **迁移学习** | 高效、快速 | 架构相对复杂 | 资源受限、快速部署 |
