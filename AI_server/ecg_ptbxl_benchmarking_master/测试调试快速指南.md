## 🔧 常见问题快速解决

### 问题0: 需要GPU训练加速
```bash
❌ 当前使用CPU训练，速度较慢
```

**解决方案**:
```bash
# 方法1: 自动安装CUDA版本PyTorch（推荐）
python install_cuda_pytorch.py

# 方法2: 手动安装
pip uninstall torch torchvision torchaudio
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

# 验证安装
python test_gpu_training.py
```

### 问题1: 预训练模型不存在
```bash
❌ 预训练模型文件不存在
```

**解决方案**:
```bash
# 运行测试脚本创建虚拟模型
python test_transfer_learning.py
```

### 问题2: CUDA内存不足
```bash
RuntimeError: CUDA out of memory
```

**解决方案**:
```bash
# 减小批次大小
python run_transfer_learning.py --config basic --batch_size 8 --device cuda

# 或使用CPU训练
python run_transfer_learning.py --config basic --device cpu
```

### 问题3: GPU训练失败
```bash
RuntimeError: CUDA error: no kernel image is available for execution
```

**解决方案**:
```bash
# 检查GPU驱动和CUDA版本兼容性
python test_gpu_training.py

# 重新安装PyTorch（确保CUDA版本匹配）
pip uninstall torch torchvision
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

### 问题3: 数据加载失败
```bash
❌ 数据加载失败: 数据文件不存在
```

**解决方案**:
```bash
# 运行数据预处理
python code/data_ltdb.py
```

### 问题4: 依赖包缺失
```bash
ModuleNotFoundError: No module named 'xxx'
```

**解决方案**:
```bash
# 安装缺失的包
pip install xxx

# 或重新安装所有依赖
pip install -r requirements.txt
```
